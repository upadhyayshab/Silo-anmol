# Delivery Guy Assignment & Rate Card Implementation Plan

## Context

The ERP system needs to implement a complete delivery management system with:
1. **Manual delivery guy assignment** - Outlet managers manually assign riders to orders
2. **Delivery service integration** - Sync orders and status updates to external delivery service
3. **Rate card implementation** - Calculate rider earnings based on per-KM and per-order rates
4. **Flexible payout scheduling** - Per outlet based (all riders in outlet follow same frequency)

## Current State Analysis

### Existing Infrastructure
- **Order Statuses**: `pending`, `delivery_allotted`, `delivered`, `cancelled`, `postponed`
- **Delivery Guy Model**: Links `user_id` to `outlet_id` with active/deleted flags
- **Order Model**: Has `delivery_person_id` field already, but no rate card integration
- **CRM Integration**: Already syncs delivery status to LeadSquared
- **Store Service**: Already fires background hooks for order status changes

### Phase 4: Earnings Calculation & Payout Flow

#### 4.1 Calculate Rider Earnings on Delivery
**File**: `app/routers/v1/rider_earnings.py` (new file)

**Rate Card Formula**: `earnings = max(minimum_charge, base_pay_per_order + (distance_km * pay_per_km))`

```python
@router.post("/calculate-earnings")
async def calculate_earnings_for_order(
    order_id: str,
    current_user_id: str = Depends(get_current_user_id)
):
    """Calculate earnings for a delivered order"""
    order = await order_manager.fetch(order_id)
    
    # Get rate card for outlet
    rate_card = await rate_card_manager.fetch_by_outlet(order.assigned_outlet_id)
    
    # Calculate distance using Haversine formula
    distance = calculate_distance_km(
        order.assigned_outlet.lat, order.assigned_outlet.lon,
        order.lat_lon[0], order.lat_lon[1]
    )
    
    # Apply rate card formula
    earnings = max(rate_card.minimum_charge, 
                   rate_card.base_pay_per_order + (distance * rate_card.pay_per_km))
    
    return {"order_id": order_id, "distance_km": distance, "earnings": earnings}
```

## Verification

### Testing Checklist
- [ ] Outlet manager can manually assign delivery guy to order
- [ ] Order status updates sync to delivery service
- [ ] Delivery service webhooks update order status

- [ ] Postponed orders update delivery service with reschedule date

### End-to-End Flow
1. Outlet manager creates order
2. Manager assigns delivery guy via `/orders/{id}/assign-delivery-guy`
3. System syncs to delivery service
4. Delivery service updates status via webhook
5. On delivery: calculate earnings, update payout records
6. Payouts generated based on outlet's configured frequency
